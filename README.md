# Clojure2048의 공식 GitHub 저장소에 오신 것을 환영합니다!

## 1. 뭐 하는 게임인가요?

JVM 기반의 Lisp 계통 언어인 Clojure로 작성된 CLI 2048 게임으로, 원본 게임 (2048)의 GitHub 저장소는 [다음과 같습니다.](https://github.com/gabrielecirulli/2048)

## 2. 어떻게 실행하나요?

Windows 환경이면 Release에 나올 .exe 파일로 실행하세요. Windows가 아니여도 JRE가 설치된 환경이면 macOS, Linux에서도 실행할 수 있습니다. 물론 Windows에서도 JRE만 있다면 .jar로 실행해도 됩니다.

## 3. 코드 상에서 실행해보고 싶어요.

Clojure가 설치된 상태면 소스코드로도 실행이 가능합니다. **단, REPL 기준 실행할 때 game2048.clj 파일 하단에 꼭 (-main)을 추가하세요!**

## 4. results.edn 파일에 있는 점수를 조작해도 되나요?
